# Slop Jumpers

Slop Jumpers is the demo application for the workshop **Beyond the Happy Path: Observability in Advance**. It’s a one-life runner set in an AI slop recycling plant. Jump over synthetic junk, collect tokens, and see which piece of slop ends your shift.

The source code is AI slop too. Treat it as unreviewed workshop material. Coding best practices took the day off.

## Start the application

Start Docker, then run this from the repository root.

```sh
docker compose up --build -d --wait
```

Open [Slop Jumpers on localhost](http://127.0.0.1:8090).
